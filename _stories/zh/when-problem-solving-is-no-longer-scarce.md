LLM 的迅速发展，让越来越多的工作可以交给机器完成。这不由得让我们思考：当那些需要多年学习和训练才能掌握的能力变得随手可得，我们应该走向何方？

我们不妨先考虑人类与 LLM 的差异。同样具有 reasoning 能力，人类和 LLM 的底层构造却大不相同。

在漫长的生物演化过程中，神经系统始终面临一个直接的要求：更快、更有效地感知环境并作出反应。轴突增粗、髓鞘的出现，都是提高电信号传导速度的演化方案。能够及时逃离危险、获取食物、协调身体的个体，通常有更大的存活机会。而长程符号推演这种思维方式，在整个生物演化过程中却不那么自然，或者说，并非自然直接优化的目标。

那么，一套长期服务于感知和反应的神经系统，是如何承担这种推演的呢？我喜欢把思考过程理解为某种意义上的联想：一部分神经元的活动引出另一部分神经元的活动。联想构成了思维的基本单元，而记忆、规则和反馈，让其中一些联想逐渐形成可以反复调用的推理路径。但要持续展开这些路径，我们还需要记住中间结果，维持各个步骤之间的关系。

语言、文字和其他符号工具的出现，形成了某种意义上的外部存储。我们可以记录从 p 到 q、再从 q 到 r 的过程，也可以把最终建立的 p 与 r 之间的联系，作为后人直接调用的结论。思维的发展由此获得了自然之外的动力：人类群体开始有意识地培养个体的思维能力，形成各种思想、理论和训练体系。今天这些系统化的推理方式，很大程度上正是后天培养的结果。借助这些工具，一套古老的神经系统得以承担越来越复杂的任务。

LLM 则与之不同。对于自回归语言模型，基础预训练直接围绕 next-token prediction 展开：根据已有上下文和模型参数，预测下一个 token。这是一种 conditional generation。进一步的后训练，又可以提升它展开多步推理和完成任务的能力。

为了培养思维能力，人类的教学通常从相对固定的映射开始：认识符号、记住定义、掌握方法，再通过各种训练进行优化。然而，如果训练主要停留在根据给定输入生成预期输出，那么它培养的很大程度上就是 conditional generation 的能力。我们又该如何凭借这种能力，与从基础训练开始就围绕这一目标优化的 LLM 竞争呢？

现代教育培养了人们的解题能力，但它的筛选机制也可能带来某种 reward hacking：分数原本被用来衡量理解与思考，学生却可能通过熟悉题型、熟练套用方法，取得漂亮的成绩。在 LLM 时代开启后，我们似乎都成了广义的“做题家”，而我们长期训练的部分能力，正变得越来越容易被 LLM 替代。当解题不再稀缺时，人类还能做些什么？

我的答案是灵感。

灵感是一个很玄妙的东西。我猜想，人类在思考时，会维持一片与当前任务相关的“记忆缓存”，其中的知识更容易被调用或引发联想，构成了人类进行 conditional generation 的基础。而灵感或许来自这片“缓存”之外的神经活动：一些原本不在当前思路中的记忆或概念，在机缘巧合下被唤起，与正在处理的问题产生联系。在我的经验里，这种激活更容易在比较放松的情况下出现。在非常专注之时，思维更加活跃，推理更加快速，但却容易局限于熟悉的联想框架。出去散散步，打打游戏，反而偶尔会冒出神奇的点子。

在我看来，灵感这种“从无到有”的能力，意味着跳出原有的问题框架，提出新的问题，或找到意料之外的方法。这也是我目前认为 LLM 较难替代的一部分。当越来越多的执行和验证工作可以交给 LLM，发现什么值得尝试、决定往哪个方向探索，会成为人类更重要的工作。（人类或许会成为新时代的随机生成器，hhh。）
